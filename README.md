# วันดี — ปฏิทินอัจฉริยะ

เว็บไซต์ปฏิทินภาษาไทยแบบ static ใช้งานได้โดยไม่ต้องติดตั้ง Python หรือใช้ API key

## เว็บไซต์

หลังเปิด GitHub Pages แล้ว: https://magaretanisshinso-creator.github.io/egg/

## เปิดใช้ GitHub Pages ครั้งแรก

1. เข้า Settings ของ repository นี้
2. เลือก Pages
3. ตั้ง Build and deployment → Source เป็น GitHub Actions
4. รอ workflow ชื่อ “Deploy Wan Dee” ทำงานสำเร็จ แล้วเปิดลิงก์เว็บไซต์ด้านบน

หลังจากนั้นทุก push เข้า `main` จะอัปเดตเว็บไซต์อัตโนมัติ

## คุณสมบัติ

- ปฏิทินล่วงหน้า 10 ปี และกิจกรรมที่เก็บไว้ในเบราว์เซอร์
- ผู้ช่วยข้อความแบบถามทีละขั้นและตัวช่วยแยกกิจกรรม โดยไม่ส่งข้อความไป API
- โหมดเรียนจับเวลาและไข่ฟัก
- กล้อง Pro ทำงานบน HTTPS หรือ localhost เท่านั้น; การตรวจจับขึ้นอยู่กับการรองรับของเบราว์เซอร์

กิจกรรมเก็บใน localStorage ของเบราว์เซอร์นั้น ๆ และไม่ซิงก์ข้ามอุปกรณ์
